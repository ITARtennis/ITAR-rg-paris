Option A — Netlify Drop (le plus simple, 2 minutes)

1
Téléchargez ce fichier HTML sur votre ordinateur (bouton ci-dessous)
2
Ouvrez app.netlify.com/drop
3
Glissez-déposez le fichier roland-garros-paris.html dans la zone de dépôt
4
Netlify génère une URL publique du type amazing-name-123.netlify.app — partagez-la sur le chat de l'agence

Option B — GitHub Pages (URL permanente)

1
Créez un compte gratuit sur github.com
2
Nouveau dépôt public → uploadez le fichier renommé index.html
3
Settings → Pages → Source : main / / (root) → Save
4
URL : votre-pseudo.github.io/nom-du-repo — accessible en permanence

Note sur la persistance des données

Les données sont sauvegardées dans le localStorage du navigateur de la personne qui administre le tableau. Pour que tout le monde voie les mêmes résultats en temps réel, une seule personne gère le tableau (le commissaire des paris) et partage des captures d'écran au moment des mises à jour importantes. Alternativement, utilisez l'option GitHub Pages et importez/exportez les données via le bouton ci-dessous.
